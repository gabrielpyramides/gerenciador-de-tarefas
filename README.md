# 📋 Gerenciador de Tarefas em Python
 
Um projeto de linha de comando desenvolvido em Python para gerenciamento de tarefas, permitindo criar, listar, editar e excluir tarefas com persistência de dados em arquivo JSON.
 
## 🚀 Funcionalidades
 
- ✅ Criar tarefas
- ✅ Listar tarefas
- ✅ Editar tarefas existentes
- ✅ Excluir tarefas
- ✅ Salvar tarefas em arquivo JSON
- ✅ Carregar tarefas automaticamente ao iniciar o programa
- ✅ Tratamento de entradas inválidas
 
## 🛠️ Tecnologias utilizadas
 
- Python 3
- JSON
- Manipulação de arquivos
- Tratamento de exceções
 
## 📂 Estrutura do projeto
 
```text
gerenciador-tarefas/
│
├── main.py
├── tarefas.py
├── persistencia.py
├── tarefas.json
└── README.md
```
 
### Responsabilidade de cada arquivo
 
- **main.py**: controla o fluxo principal da aplicação e exibe o menu de interação.
- **tarefas.py**: contém as funções relacionadas ao gerenciamento das tarefas.
- **persistencia.py**: responsável por salvar e carregar os dados do arquivo JSON.
- **tarefas.json**: armazena as tarefas cadastradas.
 
## ▶️ Como executar
 
Clone o repositório:
 
```bash
git clone https://github.com/gabrielpyramides/Gerenciador-de-Tarefas.git
```
 
Acesse a pasta do projeto:
 
```bash
cd gerenciador-de-tarefas
```
 
Execute o programa:
 
```bash
python main.py
```
